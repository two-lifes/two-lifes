## 👋 About me

Frontend engineer with 3+ years of commercial experience in **React**, **TypeScript** and **JavaScript**.
I design scalable application architecture, complex interfaces and reusable components, and I take tasks
from technical design all the way to production.

- 🧩 Built a **React + TypeScript UI kit** that standardized the interface and removed duplicated code across the team
- 🗂️ Moved global state to **Redux Toolkit** and server data to **RTK Query** — caching, tag invalidation, no manual loading flags
